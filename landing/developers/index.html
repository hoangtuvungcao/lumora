Một bot, vài dòng mãA bot in a few lines

Bot là một tài khoản Lumora do đoạn mã của bạn điều khiển. Người dùng tìm bot bằng @tên, trò chuyện như với bạn bè; tin nhắn được mã hoá đầu cuối. Không cần thuê máy chủ, không tốn phí: bot chạy ngay trên máy tính của bạn qua Lumora Bot Runner.A bot is a Lumora account controlled by your code. People find it by @username and chat with it like with a friend; messages are end-to-end encrypted. No server to rent, no fees: the bot runs on your own computer through Lumora Bot Runner.

  1. Tạo bot trong Xưởng Bot của ứng dụng và lấy token.Create the bot in the app's Bot Studio and get a token.
  2. Cài SDK Python hoặc JavaScript và tải Lumora Bot Runner.Install the Python or JavaScript SDK and get Lumora Bot Runner.
  3. Đặt token vào LUMORA_BOT_TOKEN, chạy bot, gửi /start.Put the token in LUMORA_BOT_TOKEN, run the bot, send /start.

Bắt đầu trong 5 phútStart in 5 minutes

from datetime import timedelta
from lumora_bot import Bot

bot = Bot()     # token: LUMORA_BOT_TOKEN

@bot.command("start", "Bắt đầu")
def start(ctx):
    ctx.reply("Xin chào! 👋", buttons=[[("Đặt bàn", "book")]])

@bot.on_callback(data="book")
def book(ctx):
    ctx.edit("✅ Đã đặt bàn 19:00")
    ctx.reply_reminder("Bàn 19:00", timedelta(hours=2))

bot.run()
import { Bot } from "lumora-bot";

const bot = new Bot();   // token: LUMORA_BOT_TOKEN

bot.command("start", "Bắt đầu", (ctx) =>
  ctx.reply("Xin chào! 👋", [[{ text: "Đặt bàn", data: "book" }]]));

bot.onCallback({ data: "book" }, async (ctx) => {
  await ctx.edit("✅ Đã đặt bàn 19:00");
  await ctx.replyReminder("Bàn 19:00", { inMs: 2 * 3600_000 });
});

await bot.run();

Quy tắc cho botRules for bots

  • Bot chỉ nhắn được cho người đã bắt đầu trò chuyện với bot, và chỉ vào nhóm khi quản trị viên nhóm thêm bot.Bots only message people who started a chat with them, and join a group only when a group admin adds them.
  • Trong nhóm, bot chỉ nhận lệnh, tin nhắc @tên của bot và tin trả lời bot, trừ khi quản trị viên cho phép "đọc mọi tin".In groups a bot only gets commands, messages that @mention it and replies to it, unless an admin allows "read all messages".
  • @tên của bot luôn kết thúc bằng "bot", ví dụ @hoamai_bot. Mỗi tài khoản tạo được tối đa 20 bot.A bot's @username always ends in "bot", e.g. @hoamai_bot. Each account can create up to 20 bots.
  • SDK tự giãn tốc độ gửi (15 tin/giây, mỗi cuộc trò chuyện 1 tin/giây sau 5 tin liền) để bot không bị coi là tin rác.The SDK paces sends (15 messages/s, 1/s per chat after a burst of 5) so the bot is never treated as spam.

Giữ token bí mậtKeep your token secret

Ai có token là điều khiển được bot của bạn. Đừng đưa token vào mã nguồn công khai. Nếu lỡ lộ, thu hồi trong Xưởng Bot (/mybots → Thu hồi mã) và chạy token mới với một thư mục dữ liệu mới.Whoever has the token controls your bot. Never put it in public code. If it leaks, revoke it in Bot Studio (/mybots → Revoke token) and run the new token with a new data folder.
