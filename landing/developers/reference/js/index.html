Bot

new Bot(options?)

A Lumora bot.

Options: name (display name for a bot made without Bot Studio, for tests), token (Bot Studio token; default $LUMORA_BOT_TOKEN, never hard-code it in public code), dataDir (identity, messages, storage and downloads; default ./lumora-bot, one folder per bot, keep it private and back it up), binary (path to lumorad; default $LUMORAD, then lumorad), about, lan (also find users on the local network), publicDirectory (let people find the bot by ID / @name), extraArgs, admins (peer ids or @name·tag handles), ratePerSec (overall send rate, default 15/s; per chat: burst 5, then 1/s), downloadsDir (default <dataDir>/downloads), autoRestart (default true), allowGroups (default true), lang ("vi"/"en": error message language), logJson, logLevel, runnerLog (Lumora Bot Runner's own log; default <dataDir>/runner.log, "" discards), helpCommand (auto /help, default true), denyText.

const bot = new Bot({ token: process.env.LUMORA_BOT_TOKEN, admins: ["@owner·k7q2xz"] });

command(name, description, fn, options?)

Register /name.

Parameters

  • name string: Command name without / (/name@yourbot works too in groups).
  • description string: Shown in the app's command menu and /help.
  • fn Handler: Handler.
  • options CommandOptions (optional): {adminOnly, role, chats: "all"|"private"|"group", hidden}. adminOnly / role restrict who may use it and hide it from the menu.

Returns this: The bot (chainable).

bot.command("ban", "Ban a user", (ctx) => …, { adminOnly: true, chats: "group" });

onMessage(fnOrFilter, filterOrFn?)

Handle incoming messages that are not commands. onMessage(fn) gets every text message; filters: pattern (regex searched in the text; the first matching handler wins and catch-all handlers don't run; the match is in ctx.match), kinds (default ["text"]; also "file", "voice", "sticker", "location", "contact", "poll", "checklist", "reminder"; null = all), chats ("all", "private", "group").

Parameters

  • fnOrFilter Handler|MessageFilter: Handler, or the filter.
  • filterOrFn Handler|MessageFilter (optional): The other one.

Returns this: The bot (chainable).

bot.onMessage({ kinds: ["location"] }, (ctx) => ctx.reply(`📍 ${ctx.body.lat}, ${ctx.body.lon}`));

onText(pattern, fn, options?)

Handle text messages matching pattern (regex, searched anywhere in the text).

Parameters

  • pattern RegExp|string: Pattern.
  • fn Handler: Handler.
  • options {chats?: Chats} (optional): Options.

Returns this: The bot (chainable).

bot.onText(/\bprice\b/i, (ctx) => ctx.reply("From 25k"));

onCallback(fnOrFilter, filterOrFn?)

Handle inline button presses on the bot's messages. Filters: data (exact; ending in * = prefix, e.g. "buy:*"), pattern (regex on the data, ctx.match).

Parameters

  • filterOrFn Handler|CallbackFilter (optional): The other one.

Returns this: The bot (chainable).

Handle received files. ctx.file has file_id, name, size, mime and preview ({kind, text, pages, lines} or null, available before downloading). Call await ctx.download() to get the file on disk. Filter: extensions (e.g. ["txt", "csv"]; such handlers win over catch-alls), chats.

use(fn)

Wrap every handled update. fn(ctx, next) must await next() to continue; not calling it stops the update (bans, per-user limits, logging).

send(conv, text, buttonsOrOptions?, options?)

async

Send a text message (paced so receivers never see the bot as spam).

Parameters

  • conv string: Conversation id (d:<peer>, g:<gid>); a bare peer id works too.
  • text string: Up to 64 KB of UTF-8 text.
  • buttonsOrOptions Buttons|SendOptions (optional): Buttons, or the options object.
  • options SendOptions (optional): {buttons, replyTo, silent, mentions, mentionAll, ttlMs}: silent = no sound/notification; mentions = peer ids; ttlMs = disappear after read.

Returns Promise<Message>: The sent message.

await bot.send(conv, "Sale today!", { silent: true, buttons: [[Button("Open", "open")]] });

Returns Promise<FileEntry>: The file transfer entry.

Low-level API

Method Description

call(cmd, args?, timeoutMs?)

async

Run any command of the Lumora JSON API and return its data. Commands bots may not use (remote control, recovery phrase, backups, passwords, calls) reject with NotAllowedForBots.

Parameters

  • cmd string: Command name.
  • args object (optional, default {}): Arguments.
  • timeoutMs number (optional, default 60000): Timeout.

Returns Promise<any>: The command's data.

Throws

  • LumoraError: The command failed (.code, .message, .detail).
  • LumoraTimeout: No answer in time.
  • RunnerStopped: Runner not running.

Storage

new Storage(path)

Key/value store saved as JSON in the bot's data folder (bot-storage.json).

set / delete / updateKey save the file atomically. If you change a nested value in place (storage.get("list").push(x)) call save() afterwards. Values must be JSON-serialisable. The file format is shared with the Python SDK.

data

property

The raw object (read-only use recommended).

Type: Record<string, any>

get(key, def?)

Value of key, or def when missing.

Parameters

  • key string: Key.
  • def any (optional): Default.

Returns any: The value.

has(key)

Parameters

  • key string: Key.

Returns boolean: Whether the key exists.

keys()

Returns string[]: All keys.

set(key, value)

Set key and save.

Parameters

  • key string: Key.
  • value any: JSON-serialisable value.

delete(key)

Delete key and save.

Parameters

  • key string: Key.

updateKey(key, fn, def?)

Replace key with fn(old) and save. Returns the new value.

Parameters

  • key string: Key.
  • fn (old: any) => any: Updater.
  • def any (optional): Value passed to fn when the key is missing.

Returns any: The new value.

bot.storage.updateKey("visits", (n) => n + 1, 0);

save()

Write the whole store to disk now (atomic replace).

toJSON()

Returns Record<string, any>: The data.

LumoraError

new LumoraError(message, code?, detail?, cmd?)

Error returned by Lumora (or raised by the SDK).

message is a plain sentence in the bot's language (new Bot({ lang })), safe to show to users; code is a stable key ("err.slow_mode", "err.admin_only", "internal", or "sdk.*" for errors raised by the SDK itself); detail is the technical cause (log it, don't show it); cmd is the command that failed.

Button(text, dataOrOptions = "", url = "")

Make an inline button. Pressing a data button sends a callback to the bot (bot.onCallback); a URL button opens the link. text and data are at most 64 chars.

Parameters

  • text string: Label.
  • dataOrOptions string|{data?: string, url?: string} (optional, default ""): Callback data, a https:// link, or { data } / { url }.
  • url string (optional, default ""): Link (alternative to { url }).

Returns {text: string, data: string, url: string: } The button.

Button("Buy", "buy:42");  Button("Site", { url: "https://example.com" });
