# Security reports

Do not post exploit details, credentials, recovery phrases, private conversations or other
people's data in public Issues or Discussions.

Use GitHub's [private vulnerability reporting](https://github.com/hoangtuvungcao/get_lumora/security/advisories/new)
for Lumora. Include the affected version, expected behavior, a minimal reproduction using
your own test devices and the potential impact. Vietnamese and English reports are welcome.

Test only your own devices and identities, or those whose owners have explicitly consented.
The existing license's responsible-research terms remain unchanged. This project does not
promise a response deadline or a security audit certification.
